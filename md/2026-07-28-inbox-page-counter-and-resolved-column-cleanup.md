# 2026-07-28 Inbox Page: Counter and Resolved Column Cleanup

## Changes

### 1. Removed duplicate pending counter from the header

The amber badge showing the pending count next to the page title ("Inbox") was removed. The counter next to the "Pending" status tab remains as the single indicator.

### 2. Resolved column hidden when viewing Pending status

The "Resolved" column (header and cell) is now only shown when the status filter is set to "Accepted" or "Rejected". When viewing Pending items, the column is hidden since those items have not been resolved yet.
