# 2026-07-28 Inbox Review Group Header Text Contrast Fix

## Changes

### Made group header names black for readability

The section headers in the Inbox Review form view (e.g., Shipper, Consignee, Dates, Details) were invisible against the orange header background. Updated the text color to forced black (`text-black`) so they are always clearly readable regardless of the background or dark mode setting.

This affects both standard groups and array groups in the review form.
