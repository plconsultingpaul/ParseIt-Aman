# 2026-07-28 Inbox Review Actions Moved to Header

## Changes

### Collapsed review header into a single line

The orange header bar on the Inbox Review page previously stacked the title ("Review: ABF - v4") and the metadata (filename, source, date) on two separate rows, making the header taller than needed.

Updated the layout so the title and all metadata items appear on one horizontal line separated by a subtle divider. This makes the header thinner and gives more vertical space to the actual form data below.
